# Open Items / Decisions Required Before Production

These are not permission to invent behavior.

1.  Exact login failure threshold and lock duration.
2.  Exact password hashing implementation after checking current
    Cloudflare Workers runtime support.
3.  Exact long-term backup snapshot cadence between 6 months and 5
    years.
4.  Exact partial-day restriction treatment in the annual
    participation-rate denominator.
5.  Exact scope of "normal schedules unavailable during an event" when
    an event covers only part of a campus/location/time.
6.  Exact file attachment size/type limits.
7.  Exact initial PWA/Web Push production enablement after checking
    current cost/platform constraints.
8.  Final Terms of Use text and Terms versioning/re-consent policy.
9.  Final Japanese product name, logo/brand accent color and icon
    library.
10. Exact proxy-registration permissions where earlier product
    discussion was ambiguous.

Implementation may scaffold for these items but must not silently choose
irreversible policy.
